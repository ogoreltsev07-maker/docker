# Docker-контейнер для развертывания СУБД MySQL

## Описание

Production-ready решение для контейнеризации MySQL 8.4 с автоматизацией обслуживания, мониторингом и системой бэкапов.

## Возможности

-  Кастомная конфигурация MySQL для оптимизации производительности
-  Автоматическая инициализация БД с тестовыми данными
-  Система автоматических бэкапов с ротацией
-  Скрипты восстановления с точками отката
-  HEALTHCHECK для мониторинга состояния
-  Интеграция с Prometheus для сбора метрик
-  Ротация логов с ограничением размера
-  Персистентное хранение данных

##  Структура проекта
mysql-docker/
├── Dockerfile # Инструкции сборки образа
├── docker-compose.yml # Оркестрация контейнеров
├── .env.example # Пример переменных окружения
├── config/
│ └── my.cnf # Кастомная конфигурация MySQL
├── init/
│ ├── 01_schema.sql # Схема базы данных
│ ├── 02_data.sql # Тестовые данные
│ └── 03_grants.sql # Настройка прав доступа
├── scripts/
│ ├── entrypoint.sh # Кастомный entrypoint
│ ├── backup.sh # Скрипт бэкапа
│ └── restore.sh # Скрипт восстановления
└── tests/
└── smoke_test.sh # Smoke-тесты
